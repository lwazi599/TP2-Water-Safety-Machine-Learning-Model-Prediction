# Citizen Science Water Quality Monitoring

## Project Overview

This project focuses on monitoring and analysing water quality data using data science and visualisation techniques.

The project includes a Jupyter Notebook and a Streamlit dashboard that allow the data to be analysed and presented in an interactive way.

## Project Files

### 1. Project Notebook
`01.TP_PROJECT_FINAL.ipynb`

Contains the data analysis, data cleaning, visualisations, and results of the project.

### 2. Streamlit Dashboard
`02.StreamlitDashboard.py`

Contains the interactive Streamlit dashboard used to display and explore the water quality data.

### 3. Dataset
`citizen-science-water-quality-monitoring-wq-parameters_local_time.csv`

The dataset used for the analysis and dashboard.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- Streamlit
- Data Visualisation
